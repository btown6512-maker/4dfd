# AI Playground — Android starter project

This is a starter Android Studio project using Kotlin and Jetpack Compose.

## Included
- Home screen with seven Explore AI activities
- 14 Learn AI lessons
- Pictures section with five illustrated AI use ideas
- Daily challenge worth 25 points once per calendar day
- Local progress and points storage
- Example descriptions for each picture idea
- Basic offline content (no internet permission is requested)

## Build
Open this folder in Android Studio on a computer, allow Gradle sync, then build the app.
This source project is not itself an APK or Google Play App Bundle (AAB).

## Before publishing
This starter needs testing and further work before release: app icon/launch screen, accessibility review,
privacy policy, content review, proper navigation polish, and a release AAB. Google Play approval is not guaranteed.
A parent/guardian should manage any publishing account and payments if required.

## Notes
Progress is stored locally on the device and is not cloud-synced. The app copies prompts to the clipboard;
it does not automatically send content to ChatGPT or another AI service.
